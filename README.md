# mente-activa-diario-Actividad
## Descripción
Aplicación web diseñada para estudiantes universitarios que permite el registro diario de emociones y la visualización de patrones mediante gráficos semanales y mensuales, promoviendo la salud mental.

## Tecnologías Utilizadas
* **Frontend:** React, TailwindCSS, Chart.js.
* **Backend:** Node.js, Express.
* **Base de Datos:** MongoDB.
* **Seguridad:** JWT (JSON Web Tokens).

* ## Guía de Instalación Local
1. Clona el repositorio: `git clone https://github.com/binattry-jpg/mente-activa-diario-Actividad`
2. Ejecuta Docker Compose: `docker-compose up --build`
3. Accede al frontend en `http://localhost:3000` y a la API en `http://localhost:5000`.
